# S2J Webinar Survey Service

Zoom Webinar 終了後アンケートの設問文書について、検査・助言・下書き分解を行う WordPress 非依存の Composer ライブラリです。

## 仕様

* 索引: [docs/specs.md](./docs/specs.md)
* 統合見取り図: [docs/service_spec.md](./docs/service_spec.md)
* 公開 PHP API: [docs/interfaces/php_api_spec.md](./docs/interfaces/php_api_spec.md)
* 使用方法: [docs/interfaces/usage_spec.md](./docs/interfaces/usage_spec.md)

改訂案と進行中イニシアチブの証跡は [docs_mod/](./docs_mod/) で起草し、確定後に `docs/` に反映します。完了証跡の索引は [docs/archive/README.md](./docs/archive/README.md) です。PHPUnit の生成物は `/coverage/` です (コミットしません)。
